## Android v1.2.6 (android-pre9) — Flat Preset Import & Prefix String Parsing Fix
- **Root Cause Resolution**:
  - In the reported Android installation (Python Engine v4.8.10), importing a flat single-preset JSON (generated by desktop **Share Preset** or Android **Export**) failed with `JSONException: Value / at prefix of type java.lang.String cannot be converted to JSONObject` (and similarly for `$`). The unpatched `MainActivity.kt` import assumed all files were named maps and unconditionally invoked `root.getJSONObject(name)` on every key, throwing on scalar setting attributes like `prefix` or `rolling`.
  - Implemented `PresetImportParser.kt` to distinguish flat presets from named maps using generated schema field names and value-shapes. Flat imports create a non-colliding `profile-N` branch (`profiles.size + 1`), while named maps and `{ "presets": ... }` wrappers retain same-name replacement and safe token merging.
  - Enforced atomic pre-validation: all entries in a named map are validated as `JSONObject`s before mutating in-memory profiles or tokens, rejecting malformed maps before consumption.
- **Verification & Testing**:
  - 6/6 Android behavioral unit tests passing via `gradle :app:testUxUnitTest` covering flat slash (`/`), flat dollar (`$`), roundtripping, named multi-map field name collisions (profiles named `prefix` or `rolling`), wrapped maps, and malformed map rejection.
  - Production JVM smoke test executed using real generated schema (`android_schema.json`, 116 fields) and compiled production parser class, proving regression on original unpatched loop and value preservation on fixed parser.
  - Full Python test suite verified: 526/526 tests passing in 28.895s (legacy source-only assertion `test_legacy_additional_tokens_are_migrated_and_hidden` removed from `tests/test_android_runtime_contract.py`).
  - Production APK successfully compiled and packaged via `gradle :app:assembleUx` (`app-ux.apk`, 43,361,513 bytes).
  - Note: No physical device or Android emulator was available; no visual verification was performed.
