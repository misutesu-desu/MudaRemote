**🆕 MudaRemote v5.0.0**

### ✨ New Features
- **Smarter `$oc` Games:** The bot now plays every `$oc` board the best way it can, so you get more sphere points from each game on average.
- **Better `$oh` Picks:** `$oh` chooses more carefully which spheres to open and gives the hidden sphere its proper value, so each board pays a bit more. If you set your own `$oh` reward priority, the bot still follows it.
- **`$oq` Takes the Red Sphere:** The bot no longer skips the red sphere in `$oq` and plays the rest of the board with a much stronger strategy, for clearly more points per game.
- **Stronger `$ot` Games:** `$ot` now works out where the ships can still be, uses Extra Chance to open safe spots first and plays the last moves more carefully, for more points per game.

### 🐛 Bug Fixes
- **Wishlist Names Match More Easily:** A wishlist name typed without its space, like `EiaiNano`, now matches the character Mudae shows as `Eiai Nano`. Different capital letters and extra spaces no longer stop a match, and the same goes for the blacklist.
- **French Wish Detection Improved:** The bot now also spots "Souhaité par" when the accent comes through in a different form, so wishes on French servers are picked up more reliably.

Restart the bot after updating.
