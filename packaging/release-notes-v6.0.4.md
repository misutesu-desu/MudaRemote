**MudaFork v6.0.4**

### Fixed
- **Perk 10 for a single character was declined.** The app answered `n` to the game bot's question for `$oi`; it now recognises the question and confirms.
- **Harem give sends every page.** The page number is only the minimum that starts a give: with 14 pages and a minimum of 2, all 14 pages go to the main. The default minimum is now 2.

### New
- **Smart sharing of good rolls.** A good roll is claimed by whichever account can claim it, whoever rolled it — the main first, otherwise an alt. This is the new default under Main & alts; the two earlier choices remain.

### Changed
- **Clearer settings.** A choice is one row that opens into its list, and fields appear only when they apply — for example, only the number for the chosen harem trigger.
