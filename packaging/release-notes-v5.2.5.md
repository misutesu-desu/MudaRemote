**🆕 MudaRemote v5.2.5**

### 🐛 Bug Fixes
- **`$rt` Works On Repeat Wishes:** If a character you already claimed this hour got released and rolled again, the bot ignored it even with `$rt` ready. It now uses `$rt` and claims it, as long as the roll is still free.
- **Cleaner Logs On Windows:** Some consoles showed codes like `←[94m` instead of colors. The bot now turns colors on by itself, and if the console can't show them you get plain readable text.

Restart the bot after updating.
