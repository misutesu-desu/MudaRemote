**🆕 MudaRemote v5.3.8**

### ✨ New Features
- **Daily Sphere Games Only:** Turn on Sphere Games: Daily Uses Only and the bot plays only your daily `$oh`, `$oc`, `$oq` and `$ot` uses. Stored uses stay in your inventory for you to play.
- **Minimum Value for `$rt`:** You can now set a separate value for `$rt`, for example 200 so `$rt` is only spent on characters worth 200 or more. Leave it at 0 to keep using Minimum Value to Claim.

### 🐛 Bug Fixes
- **Scheduled `$dk` Fires On Time:** If the bot was waiting for its next roll reset, a scheduled `$dk` could wait until that reset. It now goes out at the time you set.

Restart the bot after updating.
