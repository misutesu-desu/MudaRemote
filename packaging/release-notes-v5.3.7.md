**🆕 MudaRemote v5.3.7**

### ✨ New Features
- **Several Auto `$dk` Times:** Auto $dk Daily Schedule now takes more than one time, for example 06:00, 18:30, and uses a `$dk` at each.

### 🐛 Bug Fixes
- **Faster Snipes:** With Snipe Delay at 0 the bot now claims right away instead of waiting a short random moment first.
- **Kakera No Longer Slows Down Snipes:** On other players' rolls the bot now claims and collects kakera at the same time, so the claim doesn't wait.
