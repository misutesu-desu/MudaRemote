**🆕 MudaRemote v4.9.1-beta.8**

### 🐛 Bug Fixes
- **Android startup reliability:** Fixed an issue where an updated engine could start with older components, causing errors while processing Mudae status messages.
- **Reliable engine switching:** Android now clears leftover components before loading the engine on a fresh start, helping updates and version changes work consistently.

### 📲 Android Update
- **Install APK v1.2.8:** Install the new `Mudaremote.apk` over your existing app, then restart the bot. An engine-only update cannot apply this fix.
