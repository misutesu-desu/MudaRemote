**🆕 MudaRemote v4.10.5**

### ✨ New
- **$rt in the Command Channel:** New option "Send $rt in the Command Channel" (Character Sniping). When it is on, an account that snipes in another channel sends its $rt in its own command channel instead, so it no longer clashes with a forcedivorce sent at the same moment.
- **Version in the Preset Editor:** The editor window title now shows the installed version.

### 🐛 Bug Fixes
- **No More $tu Spam:** While Mudae said "You can't react to kakera", the bot kept sending $tu every few seconds. It now reads that line as a normal status, and it never sends more than 4 $tu per minute.
- **Kakera Loot $kl Prompt:** Kakera loot now answers a $kl prompt even when it arrives without a reply or mention.
- **Readable Cloud Logs:** Cloud activity logs no longer hide ordinary messages as "[REDACTED_TOKEN]".

Restart the bot after updating.
