# Mudae kakera artwork

The bundled `kakera*.png` artwork is sourced from the [Kakera Reactions](https://mudae.fandom.com/wiki/Kakera/Reactions) page and existing `sp*.png` artwork from the [Ourospheres](https://mudae.fandom.com/wiki/Ourospheres) page on the Mudae Wiki on Fandom. `spM.png` is a local visual fallback derived from the supplied megasphere reference; when the bot sees the real Discord emoji, it caches the CDN artwork over the fallback.

Source file pages use Fandom community content licensing (CC BY-SA). The preset editor uses these images only as visual identifiers for the corresponding Mudae emoji options.
